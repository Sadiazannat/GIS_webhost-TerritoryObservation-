# GIS_webhost-TerritoryObservation-
LTFN Territory Observation 
This portal was created using open-source data to support Emergency Management for Lheidli T'enneh First Nation, providing a centralized view of wildfires, historical floodplains, and evacuation orders within the Territory
For additional information and planning, you can access the official BC Wildfire Service map, smoke forecast, and temperature forecast by clicking the "i" (Information) icon in the bottom-left corner of the portal
